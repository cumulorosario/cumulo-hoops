🔒 Contraseñas de acceso

Cada pantalla puede tener su contraseña. Los dispositivos la ingresan una sola vez y quedan habilitados. Quien entra como operador también puede abrir el tablero y el reloj de 24. Este celular siempre tiene acceso, sin contraseña.

Quién puede cargar puntos, faltas, relojes y fotos.
Para la TV grande. Conviene un número corto, fácil de escribir con el control remoto.
Para las TVs chicas de posesión.
En las TVs: abrí el navegador, escribí la dirección del tablero o del reloj de 24, ingresá la contraseña si la tiene y presioná OK una vez para activar la chicharra y la pantalla completa.
Varios operadores: se puede abrir la mesa de control en más de un dispositivo a la vez; todos ven y cargan lo mismo.
